# TeamLoad Pro ⚽📊

Sistema integral de **control de cargas de entrenamiento, percepción del esfuerzo (RPE) y monitoreo de rendimiento deportivo**.

## 🚀 Características Principales

* **Modo Kiosco de Votación Rápida:** Diseñado para tablets o dispositivos a pie de campo/vestuario donde los deportistas registran su nivel de esfuerzo tras cada sesión en pocos segundos.
* **Panel de Súper Usuario / Entrenador:** Acceso protegido por PIN para preparadores físicos y cuerpo técnico con análisis de ratios de carga (ACWR), historial y métricas avanzadas.
* **Multiplataforma:** Soporte completo para **Android, iOS, Web y Windows**.
* **Identidad Visual 3D:** Branding deportivo profesional y responsivo.
* **Backend en Firebase:** Base de datos Cloud Firestore en tiempo real y autenticación.

## 🛠️ Tecnologías

* **Flutter & Dart**
* **Firebase Core & Cloud Firestore**
* **Fl Chart** para visualizaciones dinámicas de carga
* **Provider** para arquitectura de estado limpia y desacoplada

Desarrollado para la optimización y prevención de sobrecargas deportivas.
